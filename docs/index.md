# 📚 Hydra 初学者指南

> 从零开始学习 Hydra 密码爆破工具，掌握渗透测试中暴力破解的核心技能。

---

## 📋 课程大纲

| # | 章节 | 难度 | 预计时间 | 核心技能 |
|---|-------|------|---------|---------|
| 01 | 安装和验证 Hydra | ⭐ 入门 | 30分钟 | 安装、验证、环境搭建 |
| 02 | 验证 Hydra 安装情况 | ⭐ 入门 | 25分钟 | 版本检查、模块列表、依赖验证 |
| 03 | 学习 Hydra 基础命令 | ⭐⭐ 初级 | 40分钟 | 命令行语法、核心参数、目标指定 |
| 04 | 破解新用户的 SSH 登录密码 | ⭐⭐ 初级 | 45分钟 | SSH 爆破、字典使用、fail2ban 绕过 |
| 05 | 使用 Hydra 攻击 HTTP 服务 | ⭐⭐ 初级 | 45分钟 | HTTP Basic Auth、表单登录、CSRF Token |
| 06 | 破解隐藏服务 | ⭐⭐⭐ 中级 | 40分钟 | 非标准端口、服务指纹、Nmap 联动 |
| 07 | 使用 Hydra 攻击 FTP 服务 | ⭐⭐ 初级 | 40分钟 | FTP 协议、匿名访问、vsftpd 配置 |
| 08 | 使用自定义字典破解 FTP | ⭐⭐⭐ 中级 | 45分钟 | 字典生成、crunch、cewl、社会工程学 |
| 09 | 使用 Hydra 攻击 Telnet 服务 | ⭐⭐ 初级 | 35分钟 | Telnet 协议、明文传输、抓包分析 |
| 10 | 破解弱口令 Telnet 密码 | ⭐ 入门 | 30分钟 | 弱口令、Top 密码字典、效率优化 |
| 11 | 调整 Hydra 攻击速度和线程 | ⭐⭐⭐ 中级 | 35分钟 | 并发调优、延迟设置、IDS 规避 |
| 12 | 破解特工的弱 SSH 密码 | ⭐⭐⭐ 中级 | 50分钟 | 综合实战、信息收集、渗透测试流程 |

---

## 🎯 学习目标

完成本课程后，您将能够：

1. ✅ 独立安装和配置 Hydra 工具
2. ✅ 熟练使用 Hydra 的各种参数和模块
3. ✅ 针对 SSH、HTTP、FTP、Telnet 等服务进行暴力破解
4. ✅ 生成和使用自定义字典
5. ✅ 优化爆破速度和规避防御措施
6. ✅ 理解暴力破解的防御方法并加固系统

## 🛠️ 环境要求

|------|----------|------|
